这台设备只列自己的服务
  • 本页只探测这台设备上正在监听的 HTTP 服务，不扫描网段，也不读取其他设备。
  • 服务要监听 0.0.0.0 或本机内网 IP，手机才能打开；只绑 127.0.0.1 的服务会被忽略。
  • 默认忽略 50000–59999 的工具内部端口；需要时用 DEVICE_NAV_ALLOW_HIGH_PORTS=1 启动。
  • 自动发现的服务改名 / 加标签 / 屏蔽：编辑本目录的 services.json，几秒内生效。
  • NAS、路由器或其他设备的手工入口：打开 编辑页 添加，保存到本机。
