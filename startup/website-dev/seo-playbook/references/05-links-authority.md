# Phase 5：内链与外链

> 哥飞把链接的作用讲得很直白：链接就是"投票"。内链是你自己给自己投票，外链是别人给你投票。**但投票只是竞争力的一部分，不是全部。**

---

## LK-01 四条地基原理（先记住，再动手）

**优先级：P0（认知前提）**

原文四句话，出自《【哥飞 SEO 教程】内页要不要加外链？记住四句话，学会五步检查》：

1. **任何链接都能够传递权重，不管是内链还是外链。**
2. **谷歌的最小排名单位是页面，首页也是一个特殊的页面。**
3. **任何页面能拿到排名的前提条件都是竞争力足够。**
4. **任何关键词搜索结果都是一个排行榜，榜上的页面之间在相互竞争。**

**为什么这四条是地基**：它们直接推翻了两个常见误区——"必须给每个内页单独买外链"（错，内链也能传权重）、"上线就该有排名"（错，你和榜上页面在竞争，需要证明自己）。

---

## LK-02 内链优先级高于外链（成本最低的杠杆）

**优先级：P0**

**要点**：先用内链把首页/频道页的权重导给目标页，再考虑花钱买外链。

**判定依据**：《内页要不要加外链？》原文第 4 步明确的操作顺序：

> "先提升权重，让自己网站首页、频道页等高权重页面有内链指向到当前页面。如果还不够，就从外面再给当前页面搞一些外链。"

以及《再聊内链建设：内链重要性不亚于外链》。

**检查方式**：
1. 目标页的入站内链数（Screaming Frog → `Inlinks`）。门槛：**≥ 3 条来自不同页面的内链**，其中至少 1 条来自首页。
2. 内链锚文本是否包含目标关键词（不是 "click here"）。
3. 是否所有内链都是 dofollow（站内不应设 nofollow）。
4. 是否存在孤岛页（入站内链 = 0）→ 必须清零。

**通过阈值**：孤岛页 = 0；目标页首页内链 ≥ 1。

## LK-03 内链结构：导航 + 面包屑 + 页脚广度 + 首页最新

**优先级：P1**

**要点**：内链不只是"相关推荐"，而是三层结构：顶部导航（主路径）、面包屑（层级）、页脚（广度）。

**判定依据**：《【哥飞SEO教程】谷歌喜欢的页面有哪些特征？》第 3 条：

> "合理的全站顶部导航，合理的面包屑导航，合理的页面层级关系和链接，都既能够帮助爬虫更好的爬网站，也能很好的帮助用户访问你的网站。特别是把新内容在首页列出来，这是屡试不爽的加快新内容被谷歌收录的好方法。"

**检查方式**：
1. 顶部导航：一级入口 ≤ 7 个，且都指向高权重聚合页。
2. 面包屑：每个内页都有，且链接真实可点。
3. 页脚：有全量分类/索引入口（承担"广度"职责，让任意页 3 跳可达）。
4. 首页"最新"模块：见 AR-03。

**通过**：四项齐全。

## LK-04 外链的本质：相关性 × 权威性，不是数量

**优先级：P0**

**要点**：一个相关行业站给的一个外链，价值高于一百个无关站的链接。

**判定依据**：出自《外链到底有什么作用？是用来提升权重还是来获取访问量，一定要分清楚》与《【哥飞SEO教程】简单总结谷歌排名到底怎么回事；Nofollow 外链也别嫌弃，对于权重提升有作用》。前者强调目的要分清（提权重 vs 引流量是两件事），后者指出即使是 nofollow 链接，对权重提升也有作用——所以"nofollow 就别要了"这个判断是错的。

补充数据点：反链占排名因素 **13%（2025 版）**，且已连续三年下降（28% → 14% → 13%）；同时新增「链接分布多样性 3%」——**内页也要能拿到外链**，不只是首页。原作《【哥飞解读】2025年谷歌算法排名因素变化》。

**检查方式**：
1. 导出外链清单（Ahrefs → Backlinks），逐条标注：来源站 DR、来源站行业相关性（高/中/低）、链接类型（dofollow/nofollow）、锚文本。
2. 计算"高质量外链"数量：DR ≥ 30 且行业相关性为高。
3. 计算"低质外链"占比：DR < 10 或明确 spam 特征（站群、目录站、批量留言）。

**通过阈值**：高质量外链 ≥ 10 条，低质外链占比 < 20%。**达不到就继续做，不要靠数量凑。**

## LK-05 用竞品差距定目标，而不是拍脑袋定数量

**优先级：P1**

**要点**：不问"我需要多少外链"，问"我的竞争对手有什么样的外链"。

**判定依据**：出自《内页要不要加外链？》第 3 步——"你想拿到靠前排名，其实就是需要把现在上榜的某些页面挤到后面去，那就去看看，哪些结果是你当前的竞争力可以拿捏的。如果拿捏不了，就需要提升竞争力。"以及《案例演示：如何分析关键词，如何对比网站，如何推断排前面的网站能够拿到排名的原因》。

**检查方式**：
1. Ahrefs → 输入目标关键词 → 看前 3 名结果的 `DR`、`Referring domains`、`Backlinks`。
2. 对比自己：差距倍数 = 对手 RD / 自己 RD。
3. 差距 > 5 倍 → 这个词当前打不动，先做低竞争长尾积累权重（转 KW-06 长尾包抄）。
4. 差距 ≤ 2 倍 → 可打，按差距补齐。

**通过**：有明确的差距数字与补齐计划。

## LK-06 外链节奏：不要一次性砸量

**优先级：P0 —— 红线**

**要点**：新站一个月突然增加上百个外链，是典型的风险信号。外链要"持续、平缓"。

**判定依据**：出自《为什么刚做完外链、排名反而暴跌? 你可能中了谷歌的"钓鱼执法"圈套！》——这篇讲的是**买来的"高质量"外链反而导致排名暴跌**的机制；以及《什么是PBN？为什么谷歌要打击PBN？我们怎么防止成为PBN？》——如果你的外链来源彼此互链成网，你会被当成 PBN 的一员一起处理。

**检查方式**：
1. 统计每月新增引荐域（referring domains）数量，画出曲线。
2. **红线**：单月新增 RD > 现有 RD 的 50%，且来源可疑 → 立即暂停。
3. 检查外链来源是否互相链接（用 Ahrefs 看这些站之间的链接关系），若形成闭环 → 判定为 PBN 风险。
4. 检查外链落地页是否集中指向首页且锚文本全精确匹配 → 过度优化信号。

**通过**：月度新增 RD 曲线平滑，无集中爆发，来源彼此不互链。

## LK-07 锚文本要分散

**优先级：P1**

**要点**：不要 100 个外链都用同一个精确匹配锚文本。

**判定依据**：出自《为什么刚做完外链、排名反而暴跌?》中对"过度优化锚文本"的分析，以及《加了500个外链，拿下$50K的MRR》里体现的自然增长路径（真实增长是品牌词 + URL + 泛词混合）。

**检查方式**：Ahrefs → Anchors 报告，统计锚文本分布。
**通过阈值**：精确匹配锚文本占比 ≤ 30%；品牌词 / 裸 URL / 泛词（"here"、"this tool"）合计 ≥ 50%。

## LK-08 可持续的外链获取方式

**优先级：P1**

**要点**：优先选择"能持续产出、不像买链接"的方式。

**判定依据**：源自《【怎么发外链】推荐一些可以自己发文章的文章发布平台（2026年9月版）》《【哥飞 SEO 教程】这个发外链的方式一般人想不到》《分享一个容易实操且快速见效的给自己网站增加几十个外链的小技巧》《新站外链做不起来，可能因为第一步就找错了地方》《上线4天获得4700个外链，他是怎么做到的？》。

**可用方式清单**（按性价比排序）：

| 方式 | 说明 | 成本 |
|---|---|---|
| 自建内容 + 可发文章的开放平台 | 哥飞每年更新平台清单，直接投稿放链接 | 低 |
| 开源项目 / 免费工具引流 | 免费版开源，闭源版收费；GitHub 自然带来外链 | 低 |
| 社区发帖（V2EX / Reddit / HN / PH） | 兼做收录加速与初始流量 | 低 |
| Resource page / 资源页收录 | 找行业资源页申请收录 | 低但慢 |
| Guest post 客座投稿 | 稳定但需内容质量 | 中 |
| Digital PR / HARO | 权重高、周期长 | 高 |

**检查方式**：每月至少完成 2 种低/中成本方式，且每条外链记录来源与日期。
**通过**：月度外链动作有记录，非"一次性采购"。

## LK-09 时间预期：3–4 个月

**优先级：P1（判断纪律）**

**要点**：外链见效需要时间。不要用两周的数据判定"外链没用"。

**判定依据**：出自《内页要不要加外链？》第 5 步：

> "目前的体感是，对于大多数关键词，持续加外链三四个月，都会开始有效果了。"

以及《【哥飞解答】第一个出海站》——第一个站"大约一周左右时间"能进前 10，前提是词极低竞争（KD<10）。**这两个时间尺度不能混用**：低竞争练手词按周，正常竞争词按月。

**检查方式**：为每个目标页建立"外链开始日期"与"排名观察节点"（第 30 / 60 / 90 / 120 天）。
**通过**：未在第 30 天就下"无效"结论。

## LK-10 内页要不要加外链：五步检查法

**优先级：P0（决策模板）**

**要点**：不是"要/不要"，而是按五步判断这一页缺什么。

**判定依据**：出自《【哥飞 SEO 教程】内页要不要加外链？记住四句话，学会五步检查》。原文五步：

| 步骤 | 检查项 | 不通过的处置 |
|---|---|---|
| 1 | **On-Page SEO 是否做好** — 内容瞄准关键词、主题聚焦 | 先改页面，别加外链 |
| 2 | **页面竞争力是否足够** — 链接权重 + 内容信息量 + 体验 + 满足需求 | 补内容与体验 |
| 3 | **关键词 SERP 各页面竞争力如何** — 能不能拿捏某个榜上页面 | 拿捏不了就换词或降级打法 |
| 4 | **怎么提升竞争力** — 先内链，再外链；同时保障内容及时性、权威性、信息量 | 按顺序执行 |
| 5 | **做的时间是否够久** — 别人做了很久，你新页凭什么马上排 | 给时间，别乱动 |

**检查方式**：对每个"没排名"的页面，按 1→5 顺序逐项打勾，**在第 1 步失败时禁止直接进入加外链**——这是最常见的资源浪费。

## 阶段出口

- [ ] 孤岛页 = 0，目标页入站内链 ≥ 3
- [ ] 面包屑 + 页脚广度入口齐全
- [ ] 高质量外链（DR≥30 且相关）≥ 10 条
- [ ] 月度新增 RD 曲线平滑，无爆发
- [ ] 精确匹配锚文本 ≤ 30%
- [ ] 每个目标页有外链起始日与 30/60/90/120 天观察节点
