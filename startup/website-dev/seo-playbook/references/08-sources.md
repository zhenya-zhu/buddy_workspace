## 覆盖方式与诚实说明

826 篇无法在一次会话内逐篇全文阅读（单篇 8–30 KB，全量约 12 MB）。实际做法分三层，**中间经过一次返工**：

**第一层：全量目录核对**
通过 `get_knowledge_list` 确认总量 826 篇。

**第二层：主题检索比对（两轮）**
- 第一轮 3 次检索（关键词难度 / 外链内链收录 / 页面结构 TDK），去重 **238 篇**。
- 第二轮 4 次检索（域名 / 性能部署 / AdSense 变现 / GSC 数据），新增 **192 篇**。
- 合计覆盖 **430 篇**（约 52%）。

第二轮是返工：第一轮只覆盖了 SEO 技术这一个域，漏掉域名、部署、变现审核、收款等整块内容。详见 `09-coverage-audit.md`。

**第三层：22 篇核心文章逐字精读**
全部标记为「原文线」的规则与阈值均来自这 22 篇原文，可直接引用（见下表）。标记为「经验线」的是我按原文逻辑推导的量化建议。

**第四层：案例类与社群类文章仅作交叉验证**
「创业网站拆解」「新词新站比赛」「社群报喜」「线下活动」类约占总量一半以上，仅用于验证数字与现象，**不单独作为规则来源**。但需注意：**反例也多在案例类文章里**（如 `blackscreen.app` 40 词居首），案例不能只当装饰看。

**未覆盖部分**：见 `09-coverage-audit.md` 第三节，其中「收款合规」「AdSense 账号审核」「AI 工具站专属打法」三块是已识别但未精读的明确缺口。

## ⚠️ 数据质量说明（重要）

知识库中存在少量**非哥飞原创、疑似第三方 SEO 推广文案混入**的文章。识别特征：

1. 结尾出现 "这是一个 wrap" 之类的生成痕迹；
2. 出现与哥飞无关的引流信息（如指向第三方网站、YouTube 频道、预约咨询）；
3. 文风与哥飞一贯口语化、案例驱动、带社群引流的风格明显不同，出现 "兄弟""记住：10个高质量外链 > 1000个垃圾外链" 这类泛泛而谈的营销句式；
4. 缺乏哥飞特有的"具体数字 + 自己实操"的证据链。

**已识别的例子 1**：《谷歌SEO 外链建设简明指南（2025更新版）》——文中出现 "这是一个 wrap" 及 `daluoseo.com` 预约咨询引导，判定为混入内容，**本清单未采用其任何结论**。外链部分改由《内页要不要加外链》《为什么刚做完外链、排名反而暴跌》《什么是PBN》等原创文章支撑。

**已识别的例子 2（作者归属错误）**：《工具出海全球收付款的流程》——ima 里标注作者为"哥飞"，但正文有三处硬证据表明不是：
1. 自述"我之前做 ThinkAny 这个项目"——ThinkAny 是开发者 idoubi 的产品；
2. 结尾推广自己的"1024 全栈开发社群"（1024.pagen.io）；
3. 开源项目指向 `github.com/all-in-aigc`——idoubi 的 GitHub 组织。
文风也明显不同：结构化编号、Build in Public 叙事、无社群引流口径。

**处理方式**：该文只在 `10-infra-payment-compliance.md` 的 PAY-05 中作**交叉参考**引用（香港账户路线、3–5 个工作日到账等），**不作为「原文线」**。收款主体与 Stripe 部分改由哥飞本人的《从注册海外公司到 Stripe 收款回国》支撑。

> **这条比第 1 例更隐蔽**：第 1 例是文风异常，容易识别；这一例文风正常、内容专业，**只有追查文中的自述产品与 GitHub 链接才能发现作者不对**。以后引用这个知识库，凡是带"我做过 XX 项目""我的社群""github.com/xxx"的文章，都要反向核验一次作者身份。

**使用建议**：后续若扩充本清单，遇到"结论过于通用、无具体案例、带外部引流"或"提到可反查的个人项目"的文章，先做原创性与作者核验再采信。
