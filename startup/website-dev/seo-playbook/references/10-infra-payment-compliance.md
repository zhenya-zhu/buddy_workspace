# 上线基建、收款与合规

> 这一块不决定你能不能拿到流量，但决定**流量能不能变成钱**。很多人 SEO 做对了，卡在这里：广告账号过不了审、Pin 码收不到、钱提不出来。

---

## PAY-01 出海账号预埋（开工前做，不是上线后补）

**优先级：P1**

**要点**：海外服务对大陆身份有风控，账号要提前注册并"养"，不能等要用时才注册——新号立刻干重活容易被判风险。

**判定依据**：《Adsense账号注册、审核、网站审核的一点经验分享》——原文明确"新注册的 Gmail 账号，不建议立即就去注册 AdSense，可以先正常使用半个月一个月，养养号"，并点名了《如果你准备出海，请提前注册好海外各种媒体、社区、服务的账号》（后者我仅见标题与转述，**未通读**）。

**检查方式**：
1. 列出本项目的依赖账号：Google（Gmail/GSC/Analytics/AdSense）、域名注册商、主机/Vercel、Stripe、社交分发（X/Reddit/Product Hunt）。
2. 每个账号检查：注册日期、是否已登录过、是否绑定备份邮箱/手机。
3. **AdSense 专用**：Gmail 注册后先正常使用 2–4 周再申请。

**通过**：所有依赖账号已存在且有过正常使用记录（≥ 2 周）。

## PAY-02 AdSense 账号与网站过审（两道门，别混）

**优先级：P0（广告变现模式）**

**要点**：AdSense 有两道独立的门——**账号审核**和**网站审核**。过了一道不等于过另一道。且真正的门槛不是"域名年龄"，是**流量与内容**。

**判定依据**：《Adsense账号注册、审核、网站审核的一点经验分享》《网站变现新手必读：AdSense 网站审核要点速览》。

**检查方式**：

**A. 账号层**
| 项 | 做法 |
|---|---|
| Gmail | 先养 2–4 周 |
| 账号类型 | 选「个人」，姓名地址填**真实中文**，不用拼音 |
| 国家/地区 | 填**真实的中国**（后续要验证真实地址收 Pin） |
| 网站字段 | 只填顶级域名，不加 `https://`、不加路径 |

**B. 网站层**
| 项 | 判定 |
|---|---|
| 广告代码 | 已部署到页面 |
| `ads.txt` | 已放根目录，**且可访问** |
| 两者关系 | 原文提醒：这两种验证方式**不是二选一，两个都要做** |
| 审核链路 | 爬虫查代码/ads.txt → 统计一段时间流量 → 抓页面看内容量 → 人工审核 |

**通过阈值（重要，纠正一个流传很广的误区）**：
> 网上教程常说"域名必须注册满 3 个月才能申请 AdSense"。**原文明确否定**：这是针对"内容少、流量小"的网站说的。社群里有朋友 7 月注册域名、8 月就过审，**不到一个月**——原因是谷歌知道这个站有流量。
>
> 所以真正的门槛是：**有流量 + 有内容**。域名年龄只是"没流量没内容"时的替代判据。

**反例判定**：如果站刚上线、零流量、只有工具页没有文字——先别提交，会被打回"添加更多内容或等流量更大再来"。

## PAY-03 Pin 码与实名认证（最容易卡死的一步）

**优先级：P0（广告变现模式）**

**要点**：广告费满 **10 美元**后，谷歌从美国寄**平信**（不是挂号信），内含 Pin 码。填了 Pin 才算实名通过，之后才会真正付款。跨境平信丢失率高，这是常见卡点。

**判定依据**：《Adsense如何收取Pin码，如何上传文件进行实名实地认证》。

**检查方式与实操**：
1. 收入到 **10 美元** → 填写真实地址 → 等信。
2. **每两周**去后台看"再次发送 Pin"按钮是否可点，可点就点——原文建议这么做以尽快凑够次数。
3. **最多发 3 次**。3 次都没收到 → 可申请线上一实名人工审核。
4. 人工审核入口（原文给出的链接，建议收藏）：
   `https://support.google.com/adsense/workflow/11033519`
5. 人工审核提交材料：**身份证照片** + **你站在所填地址旁标志性建筑旁的照片（人+地标同时入镜）**。原文案例：照这个方法提交，次日通过。

**通过**：Pin 已录入 或 人工审核已通过。
**注意**：谷歌**最少 100 美元**才付款。所以 Pin 码在 10 美元就该处理，不要等到 100 美元才发现收不到信。

## PAY-04 收款主体：要不要注册海外公司

**优先级：P1（要在海外平台收款/上架时升级为 P0）**

**要点**：注册海外公司的目的只有一个——**拿到稳定、不被风控的收付款通道和银行账户**。很多海外服务不对大陆主体开放，或对大陆身份有更严格风控。

**判定依据**：《从注册海外公司到 Stripe 收款回国》（哥飞，实操记录）。注意：此文含 Firstbase / Wise 推荐链接与优惠码，属推广型实操文，**成本数字请以当期报价复核**。

**检查方式**：先判断自己需不需要。

| 场景 | 是否需要海外主体 |
|---|---|
| 只放 AdSense | **不需要**。AdSense 可用个人身份 + 国内地址收款 |
| 卖订阅（Stripe） | 需要。Stripe 不接受大陆个人主体 |
| 上架 App Store / Google Play 收费 | 需要（或至少强烈建议） |
| 只做联盟/佣金 | 视平台而定，多数不需要 |

**两条路径对比（原文给出）**：

| | 英国公司 | 美国公司 |
|---|---|---|
| 注册难度 | 简单、便宜（1st Formations 自助，扫码护照全流程线上） | 需代理，流程长 |
| 周期 | 1 周多 | 约 2 周 |
| 成本 | 几十刀 | 下文清单 |
| 开户 | Wise 企业账户（2023 年底起收紧，曾等 1 个月） | Mercury（EIN 后 1 个工作日） |
| 备选开户 | 万里汇（WorldFirst，阿里系，相对易开） | — |

**美国路径的完整链路（原文实操顺序）**：
1. 海外手机号：英国 giffgaff（180 天发条短信保号，约 0.3 英镑）或美国 Ultra Mobile PayGo（$3/月）
2. 注册公司：Wyoming LLC（适合个人开发者）
3. 租私人地址 + Notarize 远程视频公证（1583 表），需驾驶证翻译件、证件与地址同页
4. 申请 **EIN**（雇主身份识别号）——原文第 10 个工作日收到国税局信件
5. **Mercury** 开户（提交 EIN + 护照，1 个工作日）
6. 注册 **Stripe** 企业账号（切中文界面、护照验证、提现绑 Mercury）
7. 顺带注册 Lemon Squeezy / Paddle（这两家**需要验证产品网站**）

**成本清单（原文 2024 年前后数据）**：美国手机号 $36/年；Firstbase 注册 $399；地址邮箱 $350/年；公司代理（含年报、报税工具）$299/年。
> 原文自己也说 Firstbase 不算便宜，注册/地址/EIN/代理/开户**都可以分别找代理或自助**。

**通过**：收款链路已画出端到端图（谁付钱 → 进哪个账户 → 怎么提 → 多久到账），且每一环有可用账号。

## PAY-05 提现与资金回国

**优先级：P1**

**要点**：Stripe 收款后在商户余额里，需要主动/自动提现到对公账户，再决定怎么消费或回国。**提现是跨境转账 + 换汇 + 清算，有时延**。

**判定依据**：
- 《从注册海外公司到 Stripe 收款回国》（哥飞）——Kraken 用大陆身份+护照注册，USDT 入金后**通过订单簿买欧元**（原文强调"不是兑换，兑换手续费很贵"），走 SEPA 汇款 1 个工作日到 Wise 欧元账户，手续费 1 欧元。
- 《工具出海全球收付款的流程》——**注意：此文经核验疑非哥飞原创**（见 `08-sources.md` 数据质量说明），仅作交叉参考：Wise / 万里汇提现一般 **3–5 个工作日**到账；香港账户路线（OCBC / 中银香港 / ZA Bank）与微信香港钱包消费。

**检查方式**：
1. 记录提现周期：从 Stripe 发起 → 到账实际用了几天。
2. 记录总损耗率：（到账金额 / 收款金额）。
3. 确认提现账户名与公司主体一致（不一致会触发风控）。

**通过**：完成过一次真实的小额提现全链路（哪怕 20 美元），并记录时效与损耗。

## PAY-06 备案：出海站到底要不要

**优先级：P2（但要早决策，影响服务器选址）**

**要点**：备案本质是**域名备案**，绑定的是"接入商"（阿里云、腾讯云等）。**用境外服务器托管境外站，不需要备案**；用国内服务器则必须备案。这是选址决策，不是 SEO 决策。

**判定依据**：《关于网站备案、域名备案的一点科普》。

**检查方式**：

| 你的选择 | 是否需要备案 |
|---|---|
| 服务器在海外（Vercel / Cloudflare / 海外 VPS），面向海外用户 | **不需要** |
| 服务器在国内（阿里云/腾讯云境内节点） | **必须** |
| 想备案 | 域名必须在**国内注册商**处注册——只有对接了工信部接口的国内注册商才能同步域名实名信息 |

**关键约束（原文）**：第二版备案系统起执行**严格接入制度**——域名在阿里云备案后，要在腾讯云使用还需**再做一次接入备案**。一个域名可绑定多个接入商。

**通过**：服务器选址与备案状态一致，且已写进部署文档。
