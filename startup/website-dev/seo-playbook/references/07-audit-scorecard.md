# 审核打分卡与红线速查

两件工具：
- **A. 红线清单** —— 命中任意一条即"禁止上线 / 立即停止后续阶段"。
- **B. 百分制打分卡** —— 量化一个站点当前的健康度，用于横向对比多个站或做上线放行。

---

| # | 红线 | 违反后果（依据） | 出处 |
|---|---|---|---|
| R1 | 正文依赖客户端 JS 渲染 | 谷歌拿到空模板，无法参与排名 | 《如何制作出SEO友好的网页？》 |
| R2 | 语言切换不改变 URL | 只有一种语言能参与排名，多语言白做 | 同上 |

## B. 百分制打分卡

六大维度，权重按其"决定成败的程度"分配，而非平均。

| 维度 | 权重 | 关键项 | 得分（0–10） | 加权 |
|---|---|---|---|---|
| 1. 选词与打法 | **30** | KDRoi 排名、intitle 供应量、SERP 前 10 类型、首页/内页打法 | | |
| 2. 站点结构 | **15** | 单一核心需求、深度 ≤3、首页最新模块、页面数受控 | | |
| 3. 页面优化 | **20** | TDH 齐全唯一、工具页正文、关键词密度、无搬运 | | |
| 4. 技术 SEO | **20** | 服务端渲染、多语言 URL、sitemap/收录、robots/canonical | | |
| 5. 链接 | **10** | 孤岛页=0、高质量外链数、节奏与锚文本 | | |
| 6. 变现与运营 | **5** | 变现模式、成本、止损线、里程碑 | | |

**计算**：加权总分 = Σ（维度得分 × 权重）/ 10

### 评分档位与结论

| 总分 | 判定 | 动作 |
|---|---|---|
| ≥ 85 | 可以放量 | 进入外链与内容扩张 |
| 70–84 | 可以上线，但有短板 | 上线后 2 周内补齐最低分维度 |
| 55–69 | 不建议上线 | 回到最低分维度重做，尤其看维度 1 |
| < 55 | 立项有问题 | 大概率是词选错了，回 Phase 1 |

### 维度 1 是主导项

权重 30 不是随便给的。原文的判断是"关键词没选对，那么后面的都白干"（《养网站防老第1.5步》）。**维度 1 得分 < 6 时，无论总分多少，一律不建议上线。**

## C. 单页能否排名的五步诊断（用于"没排名"的具体页面）

按顺序，不可跳步。若在第 N 步失败，**禁止直接去加外链**——这是最常见的资源浪费。

```
1. On-Page 做好了吗？        → 否：改页面（TDH、主题聚焦、内容量）
2. 页面竞争力够吗？          → 否：补内容信息量 + 提升体验
3. SERP 上哪些页面可以拿捏？  → 拿捏不了：换词 / 换打法
4. 提升竞争力：内链优先，外链其次 → 执行
5. 时间够久吗？              → 不够：等（正常词 3–4 个月）
```

出处：《【哥飞 SEO 教程】内页要不要加外链？记住四句话，学会五步检查》

## D. 流量下滑诊断树

```
流量/曝光下滑
├─ GSC 有手动操作提示？
│   └─ 是 → 先处理处罚，停止一切改动
├─ 是"某天突然断崖"还是"缓慢下滑"？
│   ├─ 断崖 → 查最近一次发版
│   │        ├─ 首页内容是否膨胀（R3）
│   │        ├─ TD 是否被批量改动（OP-11）
│   │        └─ 是否新增大量低质页/外链（R4/R7）
│   └─ 缓慢 → 查竞争力
│            ├─ 竞品是否新增高质量内容/外链
│            ├─ 自己的内容是否过时（OP-09）
│            └─ 采集/搬运是否累积（R9）
├─ 只是某些词掉了，还是全站？
│   ├─ 单词 → 该页竞争力问题，走 C 五步
│   └─ 全站 → 站点级信号（技术/处罚/外链）
└─ 收录数是否同步下降？
    ├─ 是 → 技术侧（R1/TD 重复/robots 误拦）
    └─ 否 → 排名侧（竞争力/内容质量）
```

## F. 常见误用提醒

- **不要把阈值当判决线。** 原文反复强调"不要停在一个数字上，打开 SERP 人工判断"（《KD 很高的词也能做》）。工具分数与人工判断冲突时，以人工判断为准。
- **不要用新站数据做否决。** 前 30 天用户行为数据不足，OP-10 记为"待定"。
- **不要跳过维度 1。** 页面优化做得再好，词选错了就是零。
- **不要把"关站"当失败。** 见 MO-04，主动关站是纪律的一部分。
