# 出海建站自检与审核清单（哥飞方法论版）

## 这个 skill 怎么用

这不是一份"读完就好"的清单，而是一套**门禁（gate）**。每个阶段有必须通过的 P0 项，未通过就不进入下一阶段——这是哥飞方法论里最强的隐含约束：**关键词没选对，后面全白干**。

五种使用方式：

1. **立项前**：跑 Phase 0 + Phase 1，输出「这个词/这个需求能不能做」的结论与理由。
2. **上线前**：跑 Phase 2–4 的 P0 项，全部通过才部署。
3. **要开始赚钱前**：跑 Phase 6 + Phase 7——广告能不能过审、Pin 码路线、钱怎么提回来。
4. **上线后 / 流量下滑**：跑 Phase 5 + `references/07-audit-scorecard.md` 打分卡，定位问题层级。
5. **AI 工具站**：在上面任一步之后，额外跑 `references/11-ai-tool-site.md`。

## 优先级定义

| 级别 | 含义 | 处理方式 |
|---|---|---|
| **P0** | 红线。违反则整站努力可能归零（不收录、被判低质、被打回） | 必须通过，不通过不上线 |
| **P1** | 决定能否拿到排名的主要变量 | 首次上线必须做，可分批 |
| **P2** | 增益项，影响上限与效率 | 有余力再做，不影响上线 |

## 十一条"一句话铁律"

排在最前面，因为它们覆盖了绝大多数失败原因。任何一条被违反，优先级高于其他所有检查。

1. **举全站之力做一个关键词。** 一个关键词一个域名，用首页去打别人的内页。（细分领域专长占排名因素约 13%，2025 版）
2. **关键词没选对，后面全白干。** 先算 KDRoi，再打开 SERP 人工看前 10。
3. **必须后端渲染。** 纯前端渲染 = 谷歌拿到空模板 = 无法参与排名。
4. **工具站也必须做内容。** 谷歌不会运行你的工具，只能读你的文字来判断工具用途。
5. **新站不要批量上页面。** 一批量就死。
6. **多语言必须换 URL。** JS 切换语言 = 只有一种语言能参与排名。
7. **页面深度不超过 3 次点击。**
8. **首页内容不要膨胀。** 首页塞进大量内页全文会稀释关键词密度、语义跑偏，直接掉排名。
9. **外链看相关性和权威性，不看数量。** 10 个高质量 > 1000 个垃圾。
10. **给足时间，但时间线要分新词和老词。** 一年内能进首页的页面只占 5.7%，其中六成要 4–6 个月；新词则 2 周进首页、1 个月进前三。**用老词的标准去要求新词会白等，用新词的标准去要求老词会误杀。**
11. **做 AI 工具站，大词必须拆场景。** 一个通用输入框接不住头像/Logo/海报/产品图这些不同任务，而排名不是永久资产——`deepai.org` 一年从 1875 万掉到 800 万。**对话类可以一页搞定，图像/视频类不行。**

## 执行约定

- 每检查一项，记录：`结论（通过/不通过/待定）`、`证据（截图、URL、数字）`、`检查日期`。没有证据的"通过"一律记为待定。
- 涉及阈值的地方，阈值是**参考线不是判决线**：哥飞原文多次强调"工具分数只是参考，必须打开 SERP 人工判断"。冲突时以 SERP 人工判断为准。
- **阈值分两类**，务必分清：**原文线**（哥飞明确给出，如 KGR<0.25、第一站 KD<10、页面深度≤3、外链 3–4 个月见效）——不可随意放宽；**经验线**（本清单据原文逻辑推导的量化建议）——可按自己站点的实际数据校准。完整对照见 `references/07-audit-scorecard.md` 的 G 节。
- 命中任一红线项（`07-audit-scorecard.md` 的 Red 列表）时，停止后续阶段，先修复。

## 覆盖说明

本清单基于 ima 知识库「哥飞公众号文章同步」（826 篇，每日同步，含至 2026-10-21 的最新文章）构建：

- **全量目录核对**：确认 826 篇总量与主题分布
- **主题检索比对（两轮共 7 次检索）**：去重后覆盖 **430 篇**（约 52%）
- **逐字精读**：**22 篇**核心文章，标记为「原文线」的规则与阈值均出自这些原文，可直接引用
- **案例类与社群类**（约占一半以上）：做交叉验证，**反例主要来自这类文章**

**已补的缺口**：收款链路、合规备案、AdSense 账号层与 Pin 码、AI 工具站专属打法（见 Phase 7 与 `11-ai-tool-site.md`）。
**仍未覆盖**：2023 上半年部分基础教程仅有标题级信息；投放买量与日韩小语种市场只有粗线条。

`references/08-sources.md` 给出完整出处，并包含**数据质量警告**——已识别 **2 篇混入的非哥飞文章**（一篇第三方 SEO 推广、一篇疑似其他开发者的文章被误标作者），均未作为规则来源。
`references/09-coverage-audit.md` 给出**覆盖率审计**：选文方法的偏差、返工后修正的 6 处内容、以及仍存在的缺口清单。
