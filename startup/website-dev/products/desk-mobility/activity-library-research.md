## 1. 本轮实际读取范围

已读 2026-10-28 提供的《上交叉综合征的非手术、非药物干预：自我管理与临床指导的证据综述》完整报告，并结合公开论文做重点交叉检查。该报告是二次研究材料，不等同临床指南，也不代表其每一条操作剂量已逐项通过独立审核。

报告覆盖主动强化/耐力、活动度/拉伸、肩胛控制、胸椎活动、人体工学与负荷管理，以及软组织处理、IASTM、呼吸、贴扎、拔罐、干针、神经松动、热/冷疗、TENS 等辅助方式。

公开仓库只保存方法族、证据限制和产品设计；不复制个人病史、身体部位组合、私密对话或源报告全文。

## 2. 值得保留的产品洞察 [推断]

用户可能需要帮助解决“方法太多、如何开始、是否愿意继续、怎样记录变化”，这比把所有方法罗列成目录更适合验证。可以把研究转为：

- **有边界的选择**：日常目标、可用时间、场地/器材、用户偏好。
- **一项可执行任务**：每次展示少量审核内容，明确示范与停止方式。
- **连续自我观察**：当次与次日分别记录，保留没有变化、无法判断与更差。
- **可解释的继续/暂停**：依据审核规则和用户主动选择，不推断诊断或组织损伤。

“尝试更多方法”只是候选需求；应访谈验证用户真正需要的是更多选项、减少选项、提醒，还是专业评估。不能因创始人对研究感兴趣就假定消费者愿意管理复杂动作库。

## 3. 对源报告的关键评审

| 项目 | 报告内容及限制 [原文转述] | 产品处理 [推断] |
|---|---|---|
| 目标 | 报告强调功能、活动能力与负荷耐受，不把姿势外观当作唯一目标 | 首版记录日常任务与主观体验，不输出“体态疾病评分” |
| 证据等级 | A/B/C/D 是报告自定义实用分级，明确不是统一 GRADE | 保存原分级体系名称；不能转成“医学认证 A 级动作”徽章 |
| IASTM | 报告引用颈痛/UCS 小型试验与较新综述，支持作为辅助；没有证明某个自刮顺序或“刮开粘连”机制 | 不能把专业治疗研究直接外推为所有用户自行操作有效且安全 |
| 长棍动作 | 原始描述更接近另一只手辅助后移；报告部分按主动抗阻等长解释，另提示被动牵拉是不同动作 | 标记“动作定义待澄清”；不得复用抗阻剂量或直接做示范视频 |
| 十二周方案 | 报告说明是实用渐进框架，非固定 UCS 试验证实的公式 | 不直接转成自动十二周治疗计划；首版仍为日常活动体验 |
| 安全筛查 | 报告列举需专业帮助的信号 | 转为专业审核后的服务适用范围提示；不能宣称排除疾病 |

动作描述不清时，不靠 LLM 猜出“标准动作”。需由内容专业人员确认起始姿势、谁主动发力、谁提供外力、运动方向、是否实际移动、范围与目标；涉及个人身体问题的进一步判断由合格专业人员处理。

## 4. IASTM 的交叉核验示例

这是局部证据核验，**不是截至今日所有 IASTM 文献的完整系统综述**。

| 来源 [原文] | 关键结果 | 可得出的边界 |
|---|---|---|
| Nazari 等，2023 期刊版（2022 在线），46 项 RCT [R1] | 综述报告极低确定性证据，未见有临床意义的功能、疼痛或 ROM 优势；仅 10 项报告相关不良事件 | 没有报告伤害不能当作证明安全 |
| Tang 等，2025，11 项试验、427 人 [R2] | 报告疼痛结局中等确定性、功能结局低确定性的获益；纳入对照、研究范围与早期综述不同 | 应区分联合治疗、结局与随访期，不用“最新一篇为正”抹掉限制 |
| 2026 年系统综述，20 项 RCT、1,420 人 [R3] | 报告疼痛和 ROM 获益，同时指出功能结果异质性和方案标准化问题 | 广泛肌骨疾病结果不等于特定居家肩部操作已获验证 |

[推断] 上述研究不能证明消费者用工具处理自选部位时具有同样效果，也不能证明“肌肉粘连被物理刮开”。这些是不同的问题，需要额外证据。首版不纳入自动推荐 IASTM 操作；可作为以后专业审核的教育主题与研究候选。

## 5. 方法族的产品优先级 [推断]

下表是**产品研究优先级**，不是医学证据等级；“优先”不表示已经批准任何具体动作。

| 方法族 | 初期角色 | 准入条件 / 当前处置 |
|---|---|---|
| 日常活动变化、工作间歇、一般人体工学教育 | 首批需求与内容验证方向 | 事实核验；不承诺设备/姿势调整治疗疾病 |
| 温和主动活动、基础活动度 | 少量具体内容候选 | 专业审核人群、动作、示范和停止规则后才开放 |
| 强化/耐力/运动控制 | 后续持续使用内容候选 | 单独审核负荷、条件与适用范围；不能按症状自动开处方 |
| 辅助肩部活动/长棍动作 | 待明确的研究候选 | 区分主动辅助、被动牵拉、抗阻等长；定义不明即阻断 |
| 自我软组织处理、IASTM | 暂作教育/证据解释候选 | 不在 Phase 0 提供自动操作推荐；另评估部位、执行与工具风险 |
| 呼吸、热/冷疗、贴扎、拔罐、TENS | 后续逐项评估 | 不以“辅助”默认低风险；证据、设备、皮肤/感觉等边界各异 |
| 神经松动、治疗性手法、干针等 | 专业评估/临床信息层 | 消费版自动跟练库排除；不能因选择麻木选项而推荐 |

报告中很多研究涉及颈痛患者、特定诊断或专业人员实施。我们的首发用户是更窄的日常工作场景；**人群、实施者、剂量、结局、场景均需逐项核对外推性**。主动运动类的较广支持，也不自动验证任意两分钟动作。

## 6. 每个活动内容对象需要什么 [工程]

| 字段组 | 必须记录 |
|---|---|
| 身份与版本 | activity_id、版本、标题、方法族、语言、发布日期 |
| 动作定义 | 起始姿势、主动/辅助/被动/抗阻类型、方向、步骤、器材、时间、示范资产 |
| 预期用途 | 面向的日常任务；允许表达与禁止表达；适用市场 |
| 研究依据 | 原始文献、研究人群、实施者、比较组、剂量、结局、随访、证据体系及限制 |
| 外推判断 | 是否适用于自我实施/当前人群；哪些方面未知；专业审阅意见 |
| 内容安全 | 排除条件、停止规则、替代/退出方式、是否需要专业指导 |
| 审核与许可 | 审核人及资质核验、日期、复查条件、图文/视频使用许可 |
| 发布与监测 | 候选/待审核/已批准/已发布/暂停/退役；版本历史与问题处理 |

轻量文件或表格即可先实现，不必建设知识图谱。临床证据、内容审核状态、用户体验反馈三个字段体系分开保存。反馈良好不能自动提升医学证据等级；论文结果积极也不能自动批准发布。

## 7. 准入与撤回流程 [工程]

**候选登记 → 定义动作 → 核验证据及外推 → 专业审核 → 可用性检查 → 限定范围发布 → 监测 / 暂停 / 更新。**

- 定义不清、来源无法追溯、缺少审核人或停止规则，保持待审核。
- 审核通过必须绑定具体内容版本、适用范围和市场；换示范、负荷、目标人群或推荐逻辑后重新检查。
- 发布前让目标用户理解并复述要点；必要的实际执行评估由合适专业人员安排。
- 安全退出/更差反馈进入已审核的停止帮助流程；不自动用更强动作“补救”。
- 发现内容风险可立即暂停该版本，入口与旧链接均不可继续启动；已有记录保留原版本以便审计。
- LLM 可辅助摘要和提出缺失字段，不能生成未经审核的新动作、覆盖停止规则或代替批准人。
