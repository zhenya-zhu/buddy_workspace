## 重要约束

- **产品定位**：low-risk self-observation / gentle desk movement，非诊断/治疗/医学处方，用户不能通过自测结果获得“你患有某疾病”的判断。
- **临床审核优先**：任何运动指导都必须先由合格专业人员审核。未审核时只做非运动体验/内容与需求验证。
- **用户数据保护**：不把健康/问卷/联系方式或付款信息放在这个公开仓库；不向普通网页分析发送敏感信息。
- **SEO 是获客渠道，不是质量证明**：健康主题为 YMYL，公开内容需专业审核、来源、作者、更新与适用边界。三种文案实验不是三个可自动索引的重复页面。
- **平台建设延后**：先 Astro + Vue + Cloudflare Staging 及单站；D1 仅在真实 7 天会话持久化需要时引入；没有需求证据不做复杂 CMS、3D、AI 诊断或多语言扩张。
- **任务与证据**：文档中的数值是来自先前讨论的早期探索参考线，不代表临床有效性或统计显著性；状态一律待验证。
