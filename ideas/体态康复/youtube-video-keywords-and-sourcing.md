## 1. 目标与关键结论

**[原文]** 搜集 YouTube 中由医生、康复医师或物理治疗师出镜，面向大众展示体态相关症状改善、活动能力训练或康复动作的视频。要求覆盖尽量多的问题类型；同时考虑医学术语、非学术俗称、患者具体疼痛和功能受限的口语表述。

**[整理]** 不要只依靠 `forward head posture`、`anterior pelvic tilt` 等名称检索。实际视频标题往往来自不同表达层：
1. **专业术语**：`scapular dyskinesis`、`thoracic hyperkyphosis`。
2. **大众俗称**：`tech neck`、`dowager's hump`。
3. **疼痛/不适**：`pain between shoulder blades`、`deep butt pain`。
4. **动作或功能受限**：`can't lift arm overhead`、`heels lift during squat`。
5. **具体训练/动作**：`serratus anterior exercises`、`thoracic rotation mobility`。

**重要区分**：这些是**搜索入口**，不是同义词映射，也不是医学诊断。例如 “Shoulder Blade Feels Stuck” 不能直接映射为肩胛运动障碍；“富贵包”外观可能关联不同的结构或组织成分，不能仅靠外观判定成因。患者描述、临床评估、动作选择应分开存储。

## 4. 查找“专业人员出镜 + 动作示范”的搜索方法 [推断]

### 4.1 身份限定词

- **医生（医学学位/执业医师）**：`physiatrist`、`physical medicine and rehabilitation physician`、`sports medicine physician`、`MD`、`DO`。
- **物理治疗师（康复运动教学核心来源）**：`physical therapist`、`physiotherapist`、`DPT`、`licensed physical therapist`。
- **演示意图**：`exercise demonstration`、`physical therapy exercises`、`rehab exercises`、`corrective exercises`、`follow along`、`home exercise program`。
- **动作进阶或理论**：`exercise progression`、`clinical reasoning`、`evidence based`、`without equipment`、`resistance band`。

**资质提醒**：DPT = Doctor of Physical Therapy（物理治疗博士），**不是** MD（医学博士）。频道简介、人物姓名、执业信息与视频实际出镜者需要分别核实；仅有标题写 `doctor` 或 `physical therapist` 不足以确认其资质。

### 4.2 搜索模板

```text
"<condition>" physical therapist exercises
"<patient description>" physiotherapist follow along
"<symptom>" physical therapy rehab routine
"<exercise>" DPT exercise demonstration
"<condition>" physiatrist exercises
"<condition>" evidence based exercise progression
"<condition>" home exercise program
"<condition>" [physical therapist OR physiotherapist] mobility
```

最后一条的 `OR` 是搜索引擎候选语法；在 YouTube 内是否严格按布尔条件解释，需要实际检查结果。优先分别运行两个身份词，降低漏检。

### 4.4 推荐检索顺序

1. **每个主题至少用三类独立查询**：医学名称、大众俗称、具体症状/受限；必要时增添动作名称。
2. **先找相关视频，再核出镜者**：没有找到专业视频时，不能因为某视频播放量大就降低身份要求。
3. **查看视频前 1–3 分钟、完整动作片段与简介**：记录是否真人演示、是否讲适用对象、次数、变式及暂停条件。
4. **按主题/动作去重**：不同标题引用同一个视频或反复展示同一动作，不能当成独立训练依据。
5. **人工复核后入库**：AI 摘要和字幕可以辅助提取，但不能代替专业审核与真人动作质量复核。

## 6. 视频筛选与准入规则 [工程/推断]

按以下四层分开记录，不能混成一个“质量分”：

| 层级 | 必填证据 | 状态 |
|---|---|---|
| 发现（Discovery） | 原始 query、URL、检索时间、标题、频道、语言 | 可自动化初采 |
| 身份（Credential） | 出镜者姓名、角色/学历、可验证资质来源 | 未核实 / 已核实 / 不符合 |
| 内容（Content） | 动作演示片段及时间戳、名称、次数、目的、变式、风险提醒 | 待人工复查 |
| 医疗/产品准入（Clinical & Product） | 适用对象/排除条件、来源证据、专业审查者与版本、许可状态 | 未审 / 通过 / 驳回 |

**建议纳入**：出镜者可识别、资质可核验、真人清晰演示、动作讲解有边界、能提取具体时间戳及训练参数的视频。

**建议排除或延期**：纯动画而无要求的真人示范；用“几分钟永久治愈”作保证；在未评估情况下宣称某个外观一定由“肌肉不平衡”造成；对神经症状、近期外伤等给出无条件自我治疗承诺；人物资质不明；许可状态无法支持预期复用。

**风险警戒**：持续/进展性麻木无力、明显外伤、急性严重疼痛、胸痛、呼吸困难等不能用姿势练习视频替代及时医学评估。对脊柱侧弯、结构性膝腿/足部形态、肩部疾病等尤其要区分可训练的功能与结构性情况。不存在适用于所有人的单一“完美姿势”，内容不能暗示所有外观差异都必须治疗。

## 7. 素材数据库建议模型 [工程]

**三个不同实体不可混用**：
- `user_expression`：用户怎样描述（症状、感受、情境、功能困难）；
- `clinical_concept`：专业概念与鉴别方向（需审查，不能从描述直接定诊）；
- `exercise`：动作及其目标、适应/禁忌、具体参数和来源。

建议视频层、片段层、动作层解耦，保留一对多关系。

| 字段 | 含义/注意 |
|---|---|
| `video_id`, `url`, `channel_id` | YouTube 唯一定位，避免仅存标题 |
| `search_query`, `query_type`, `fetched_at` | 可追溯检索路径；类型如 `clinical / colloquial / symptom / functional / exercise` |
| `presenter_name`, `presenter_credentials`, `credential_source` | 身份核查，不能据频道名自动填充 |
| `condition_tags`, `symptom_tags` | 标签，不当作诊断 |
| `exercise_name`, `target_area`, `goal` | 标准动作名称、区域、教学目标 |
| `start_sec`, `end_sec` | 真人动作演示片段时间戳 |
| `sets`, `reps`, `hold_seconds`, `frequency` | 仅在视频明确给出时记录 |
| `difficulty`, `equipment`, `progression`, `regression` | 不同用户与器械条件 |
| `cautions`, `contraindications`, `clinical_refs` | 安全提醒、证据与不确定性 |
| `license_status`, `reuse_rights` | 公开可看不等于商业再分发授权 |
| `review_status`, `reviewer`, `reviewed_at`, `content_version` | 通过专业人工审核后方可进入推荐集 |

**可验收的数据规则**：一个搜索命中不是一个已验证动作；缺乏资质/时间戳/参数必须用 `unknown` 或空值，不得猜测；`review_status != approved` 的内容不得用作产品级自动个体化运动指导。

## 8. 与 Desk Mobility 第一站的关系 [推断]

全身体态词库是**长期内容研究资产**，不等于 MVP 立即覆盖 54 类问题或 1,144 条词。结合现有产品计划，第一轮可以从 **久坐/电脑工作、颈部活动、肩带/胸椎活动** 中挑选少量已审核动作与表达，验证用户是否理解、完成和愿意重复；其他类别先做内容索引与研究储备。

- [研究和产品边界](./research-and-boundaries.md)：更高层的研究边界与医疗风险；
- [详细活动库研究](../../startup/website-dev/products/desk-mobility/activity-library-research.md)：动作内容准入及审查；
- [验证路线](./validation-and-decisions.md)：只把研究素材转化为可检验的产品假设，不当作用户需求或治疗效果已验证。
