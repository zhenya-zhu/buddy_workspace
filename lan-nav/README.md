# 局域网导航页与设备服务自发现

把各台机器上正在开发的 Web 服务集中到一个页面，用手机 / iPad 打开 `http://192.168.31.94:8000` 就能点进去，不用记 IP 和端口。

> [工程] 零第三方依赖：全部使用 Python 3 标准库 + 单文件 HTML。本目录是 `buddy_workspace` 中除 `vps_manage/` 外的第二类本机运维工具，不承载任何站点业务逻辑。
> 状态：已在常驻 Mac（`192.168.31.94`）验证；其他机器需各自部署 `agent.py` 后才会出现在「自动发现」分组。

## 1. 角色与文件

| 角色 | 文件 | 说明 |
|---|---|---|
| **常驻 Mac（中心）** | `server.py` | 静态服务 + 保存条目 API + 后台定时扫描 |
| | `discover.py` | 每 120 秒只探测各设备 9700 端口，汇总服务清单 |
| | `index.html` | 导航页：常用入口 / 正式版 / 测试版 / 实验项目 / 自动发现 |
| | `edit.html` | 浏览器里增删改手工条目（Windows / 手机也可用） |
| | `sites.json` | 手工条目的数据源 |
| | `start-mac.command` | Mac 一键启动（优先 `/usr/bin/python3`，避开 macOS 防火墙问题） |
| **每台开发机（Agent）** | `agent.py` | 监听 9700，上报本机 Web 服务清单（仅标准库） |
| | `services.json` | 可选：改名 / 备注 / 标签 / 屏蔽端口 |
| | `start-agent.bat` | Windows 一键启动 |
| | `start-agent.command` | Mac / Linux 一键启动 |
| **文档** | `给其他机器Agent的接入指南.md` | **给其他机器上的 Agent 看的自包含操作手册** |
| | `需求与部署备忘.md` | 原始需求、方案决策、验证记录与待办 |

运行时生成的 `discovered.json`（扫描结果）不入库。

## 2. 协议

每台开发机在固定端口 **9700** 提供：

```http
GET http://<设备IP>:9700/services
```

返回 JSON，关键字段为 `device`、`ip`、`registryPort`、`services[]`；每个 `services[]` 元素含 `name` / `url` / `desc` / `tag` / `port` / `title`。Mac 端按地址与 `sites.json` 去重，合并到导航页「自动发现」分组。

代理只上报绑定在 `0.0.0.0` / 本机内网 IP 的 HTTP 服务；`127.0.0.1` 独占监听、50000–59999 工具端口、返回 403 且无标题的系统服务会被过滤。

## 3. 快速使用

**中心（Mac）**：双击 `start-mac.command`，保持终端窗口打开。

**开发机（Windows）**：把 `agent.py`、`services.json`、`start-agent.bat` 放同一目录，双击 `start-agent.bat`；长期运行请把快捷方式放进「启动」文件夹。

**验证**：

```bash
curl http://127.0.0.1:9700/services          # 开发机本机
curl http://192.168.31.94:8000/             # 导航页
```

详细配置、验证清单、排障表和 Agent 行为边界见 [给其他机器Agent的接入指南.md](./给其他机器Agent的接入指南.md)；方案沿革与网络拓扑见 [需求与部署备忘.md](./需求与部署备忘.md)。

## 4. 约定

- 注册端口固定 9700；改端口需同时修改 Mac 端 `REGISTRY_PORT` 与设备端 `AGENT_PORT`。
- 开发服务须监听 `0.0.0.0`（如 Vite `--host 0.0.0.0`）才能被手机访问并被代理上报。
- 「常用入口 / 正式版 / 测试版 / 实验项目」由 Mac 端手工维护；自动发现的条目统一进「自动发现」，避免机器误分类。
- 外网访问依赖 Tailscale 子网路由（部署在 Mac）；手机翻墙 VPN 需把 `100.64.0.0/10` 与 `192.168.0.0/16` 设为直连。
- 代理不写日志、不采集页面正文，只读取 `<title>` 用于命名。
