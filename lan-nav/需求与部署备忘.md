# 局域网导航页 · 需求与部署备忘

> 2026-11-27：本方案已被 [`../device-nav/`](../device-nav/README.md) 取代——改为每台设备维护自己的页面，不再需要 Mac 统一扫描和 9700 注册。本文保留作为历史决策记录。

## 核心目标

搭建一个单一入口的局域网导航网页，把各台机器上正在开发的网页服务集中起来，用手机或 iPad 直接点开访问，不用记 IP 和端口。页面按「常用入口 / 正式版 / 测试版 / 实验项目 / 自动发现」分组；每台设备通过固定端口 9700 注册自己的服务，Mac 只探测这一个端口，不需要手工填写。

## 设备与网络

- Windows PC：`192.168.31.22`；常驻 Mac（MacBookPro）：`192.168.31.94`；NAS（EzioNas.local，群晖）：`192.168.31.111`
- 未识别设备：`192.168.31.173` / `.180`（是否深查待定）
- 网段 `192.168.31.0/24`，小米路由器网关 `192.168.31.1`
- 用户在中国大陆，手机翻墙 VPN 与内网访问互不干扰

## 方案决策

| 事项 | 决定 |
|---|---|
| 导航页跑在哪 | 常驻 Mac（NAS 资源少、操作麻烦） |
| 技术形态 | 零外部依赖：导航页是单文件静态 HTML，Mac 上用 Python 标准库小服务托管（静态文件 + 保存接口），不用 Docker |
| 条目维护 | 数据独立存 `sites.json`；Windows / 手机浏览器打开编辑页即可改，Mac 页面 30 秒内自动刷新 |
| 服务发现 | 每台设备跑 `agent.py`，在固定端口 9700 上报服务清单；Mac 每 120 秒只读取各设备的 9700 端口，结果存 `discovered.json`，与手工条目按地址去重 |
| IP 漂移 | 路由器 DHCP 静态绑定固定 IP + Tailscale 组网结合 |
| 链接写法 | 统一写固定内网 IP，局域网直连与 Tailscale 子网路由共用同一套地址 |
| 外网访问 | 手机在外只开 Tailscale，经 Mac 的子网路由回家，访问自己设备不需要翻墙 VPN |
| VPN 共存 | 代理软件把 `100.64.0.0/10`、`192.168.0.0/16` 设为直连；iOS 建议用内置 Tailnet 的客户端 |

### 已发现并解决的问题

macOS 应用防火墙会拦截第三方 Python（如工具内置 / Homebrew 版本）的传入连接：浏览器访问本机局域网 IP 时连接建立后被立即断开。启动脚本因此**优先使用 `/usr/bin/python3`**（防火墙默认放行），更换 Python 后局域网地址验证通过。

本次检测时 PC `.22` 与 NAS `.111` 的 ARP 记录存在，但 ICMP / SMB 445 均不响应（可能关机或休眠）；导航页本身不依赖这两台机器。

## 使用方法

1. 在常驻 Mac 上双击 `start-mac.command`（终端窗口需保持打开）；脚本会自动打开编辑页。
2. 手机 / iPad 连接同一 Wi-Fi，浏览器打开 `http://192.168.31.94:8000`。
3. **在 Windows PC 上维护条目**：浏览器打开 `http://192.168.31.94:8000/edit.html`，增删改后点「保存到 Mac」；导航页 30 秒内自动更新，也可点右上「刷新」。
4. **在各开发机部署注册代理**（Windows 需 Python 3）：把 `agent.py`、`services.json`、`start-agent.bat` 拷到同一目录，双击 `start-agent.bat`；Mac 上对应 `start-agent.command`。之后本机所有监听在 `0.0.0.0`/局域网 IP 的 HTTP 服务会自动上报。
5. 需要自定义名称/分类时，编辑该机的 `services.json`（字段：`name` / `port` / `desc` / `tag` / `enabled`）；把某端口设为 `"enabled": false` 即可屏蔽。默认屏蔽 50000–59999 的工具内部端口。
6. Mac 每 120 秒读取各设备 9700 端口，结果出现在「自动发现」分组；点导航页右上角「扫描」可立即重扫。
7. 端口冲突时用 `PORT=8001 ./start-mac.command` 换导航页端口；代理端口可用 `AGENT_PORT=9701` 修改（需同步改 Mac 端 `REGISTRY_PORT`）。
8. 也支持直接改 `sites.json`（字段：`group` / `name` / `url` / `desc` / `tag`）；如需给编辑页加口令：`NAV_EDIT_TOKEN=your-token ./start-mac.command`。
